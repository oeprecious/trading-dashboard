# trading-dashboard

Interactive trading dashboard with trade logging, local storage, dynamic calculations and responsive UI.

**Live Demo:** https://tradingplandashboard.netlify.app/

## About
A personal trading journal dashboard to log trades, track daily performance, and calculate P&L. Built for traders to have a fast, offline-first tool without backend.

## Features
- Add / Save Trades (Pair, Entry Price, Stop Loss, Take Profit, Result, PnL)
- Recent Trades list
- Today's Summary (P&L Today, Total Trades)
- Dynamic P&L calculation
- Local Storage persistence
- Responsive UI for mobile and desktop

## Tech Stack
- HTML5
- CSS3
- Vanilla JavaScript
- LocalStorage API

## How to Run
1. Clone: `git clone https://github.com/oeprxc/trading-dashboard.git`
2. Open `index.html` in your browser
